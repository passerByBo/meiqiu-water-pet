# 3D 宠物模型制作流程（AI 生成 → Blender 绑骨 → 煤球）

第一只黑猫（2026-10-29）走通的流程和踩过的坑，做柴犬、仓鼠、金鱼时照着来。

## 一、整体流程

```
Tripo 文字生成（H2.5 / 2K / 1 万面，30 积分）
  → 导出 GLB（免费版每月 15 次，只能导出 H2.5）
  → 放到 assets/models/raw/
  → Blender 里跑 tools/blender/rig_quadruped.py 自动绑骨（不花积分）
  → 摆姿势检查变形
  → 导出 assets/models/<动物>.glb（带骨骼，不带动画）
  → 煤球代码里用 GLTFLoader 加载，按 KEY_POSES 用代码驱动骨骼
```

## 二、Tripo 生成设置（省积分 + 能导出）

| 设置 | 选什么 | 原因 |
|---|---|---|
| 入口 | 3D 工作台 → 模型 → 铅笔标签（文字） | 首页那个框只能传图片 |
| AI 模型 | **H2.5 – 经典版本** | 免费版**只能导出 H2.5**，选 H3.1 生成了也下载不了 |
| 几何与纹理 → 纹理质量 | 2K | 4K 更贵，桌宠用不上 |
| 几何与纹理 → 面数控制 | **10000** | 默认 200 万面，太大 |
| T-姿势 | **不开** | 那是给人形角色用的 |
| 结果 | 每次 30 积分 | 默认设置要 55 |

- **"免费重试"在免费版用不了**（要升级），而且它是用原描述重新生成，改了描述只能重新付积分生成。
- **不要用 Tripo 的自动绑定**（20 积分）：选"其他"类型没有骨骼预设，骨骼结构不受控制，和代码对不上。我们自己在 Blender 里绑，骨骼名直接和代码一致。

## 三、提示词模板（四足宠物）

```
A cute chibi 【动物和毛色】 standing still on all fours, quadruped stance like a real 【动物】, horizontal body,
all four paws flat on the ground, symmetric standing pose, not walking, four legs evenly spaced and clearly separated,
slightly longer legs with a visible gap between belly and ground,
soft fluffy fur texture, visible fur tufts on cheeks chest and tail, plush toy look, matte fur, no shine, no gloss,
oversized round head, big 【眼睛颜色】 eyes, 【特征：耳朵/鼻子/花纹】, mouth closed,
【尾巴描述】 clearly separated from the body,
stylized cartoon desktop pet, game asset, full body, single character, no base, no background
```

要点（都是黑猫踩出来的）：
1. **必须写 `on all fours, quadruped stance, horizontal body`**。只写 "standing on four legs" 会生成成**两腿直立的卡通猫**，和代码的四足骨架（`BlackCatModel.ts` 的 hips/chest + 四条腿）对不上。
2. **必须写 `standing still, all paws flat on the ground, symmetric standing pose, not walking`**。黑猫生成出来有一条前腿在往前迈、脚掌翘离地面 2.5cm，结果在桌面上**一只脚一直抬着，站着、走路都别扭**，只能在 Blender 里手动把腿摆直（见第四节"修腿"）。
3. **禁止写 `smooth clean surfaces` / `glossy`**，要写 `soft fluffy fur texture, plush toy look, matte fur, no shine`。黑猫用了 smooth，结果表面**像皮球一样反光、没有毛发感**（Tripo 给的粗糙度只有 0.25，是塑料的数值）。
4. **腿别太短**：黑猫的腿很短、肚子几乎贴地，抬腿迈步时像一截短桩。加 `slightly longer legs, visible gap between belly and ground`。
5. **尾巴写清楚方向**：竖起来的尾巴（`tail raised`）脚本能自动找到尾根；垂下来或卷在身上的尾巴，要手动传 `tail_base`。
6. `mouth closed`：张嘴会让头部网格更复杂，不好绑。
7. 眼睛别写 `glossy eyes`：眼睛会被一起做成高光塑料感。

## 三点五、花积分之前的检查（免费版积分和导出次数都有限）

**生成前**（每次 30 积分）：
- [ ] 提示词里有 `on all fours` `standing still` `all paws flat on the ground` `not walking`
- [ ] 提示词里有 `fluffy fur` `matte` `no shine`，**没有** `smooth` `glossy`
- [ ] 模型 H2.5、纹理 2K、面数 10000（设置会被记住，但每次都看一眼按钮上是不是 30）

**生成后、导出前**（导出每月只有 15 次）——在 Tripo 预览里转一圈，**有下面任一问题就不要导出**：
- [ ] 侧面看：四只脚都踩在地上，没有哪条腿往前迈或抬起来
- [ ] 正面看：左右两边的腿大致对称
- [ ] 表面有没有一块块的亮斑（像塑料、皮球）——有的话导出后要按第四节"去反光"处理
- [ ] 尾巴、耳朵和身体分开，没有粘在一起
- [ ] 贴图有没有明显的色块瑕疵（黑猫尾巴上有一道灰白条纹）

小问题（轻微反光、一点色块、一条腿稍微不直）可以在 Blender 里修，不用重新生成；
两腿直立、腿粘在一起、整体造型不对，就只能重新生成。

## 四、Blender 绑骨（tools/blender/rig_quadruped.py）

```python
exec(open(r"D:/woke/homework/gongju/tools/blender/rig_quadruped.py", encoding="utf-8").read())
armature, report = rig_quadruped("黑猫", tail_bone_count=4, armature_name="黑猫_骨架")
```

- 骨骼：`hips → chest → neck → head`；`chest → frontLeft/frontRight_upper → _knee`；`hips → backLeft/backRight_upper → _knee`；`hips → tail_0..tail_N`。和 `BlackCatModel.ts` 的关节一一对应。
- 坐标约定：Tripo 的 GLB 导入后**脸朝 -Y、脚底在 z=0**。左 = -x。导出为 glTF（Y 轴朝上）后正好是 Three.js 里脸朝 +Z，和现有代码一致。
- 仓鼠这种几乎没有尾巴的：`tail_bone_count=0`。
- 跑完看 `report`：`没有权重的顶点` 应该是 0。

### 脚本里处理掉的坑
| 现象 | 原因 | 处理 |
|---|---|---|
| 网格断成 15 块，自动权重可能失败 | glTF 在贴图接缝处把顶点拆开了 | 先合并重合顶点（6217 → 5002），UV 不会丢 |
| 按 x 正负分左右脚分错了 | AI 模型不对称，有一条腿往里迈 | 取贴地顶点做 4 类 k-means 聚类 |
| 横切找腿，四只脚连成一块 | 腿太短，肚子也被切进去了 | 只取最贴地的 6% 高度当"脚底" |
| 包围盒看着左右对称，其实身体偏到 +x | 胡须左右支出去，把包围盒撑大了 | 用身体中段截面算中心，不用包围盒 |
| 尾根被算到后脚上 | 测地追踪从尾巴一路走到屁股和腿上；"截面变粗""离表面距离"两种判断在 AI 模型上都不准 | 改成"中心线低于背部高度 90% 处就是尾根"，并支持手动传 `tail_base` |

### 检查变形
摆这几个姿势，从侧面、正面、背面截图，看有没有撕裂、穿模、凹陷：转头、尾巴甩到一边、一条前腿抬起、坐下。黑猫全部通过。

### 修腿（有腿没站直时）
**约定：模型的静止姿势就是"四脚站好"**，代码（`GltfQuadrupedModel.ts`）不再纠正腿的角度。所以腿没站直必须在 Blender 里修：
1. 姿态模式下转动这条腿的 `_upper` / `_knee`，量脚掌最低点和前后位置，和对侧的脚对齐（黑猫右前腿：大腿 +0.15、膝盖 +0.25）。
2. 腿翘着就把**整条腿**往下挪（挪 `_upper` 的位置；`_knee` 和大腿是连着的，挪了没用）。黑猫下压了 3cm。
3. 烤成静止形状：网格上**应用**骨骼修改器 → 重新加一个骨骼修改器指向骨架 → 骨架姿态模式里"应用为静止姿态"（`bpy.ops.pose.armature_apply`）。
4. 量一遍四只脚的最低点都 ≈ 0 再导出。

### 去反光（表面像塑料、皮球时）
Tripo 的 `_rm` 贴图（G 通道是粗糙度，B 通道是金属度）。黑猫粗糙度中位数只有 0.25：
- 在 Blender 里把 G 通道改到 0.88~0.95（保留一点起伏），B 通道清零，再导出。
- 代码里 `GltfQuadrupedModel` 会再把材质换成**哑光 + 绒光（sheen）**的毛绒材质，边缘有一层柔光，正面没有亮斑。毛色偏浅的动物可以把 `sheenColor` 调亮一点。

### 修贴图色块
黑猫尾巴上有一道灰白条纹：用尾巴骨头的权重找出尾巴在贴图上的三角形区域，只把其中偏亮（亮度 > 0.26）的像素按比例压回毛色。

### 导出
`export_skins=True, export_animations=False, export_yup=True, export_image_format='JPEG', export_image_quality=88`，只选模型和骨架。
- **一定要用 JPEG**：改过的贴图默认会存成 PNG，文件从 1.5MB 涨到 3.7MB；用 JPEG 是 0.75MB。
- 会有一条警告"顶点受超过 4 根骨骼影响，只保留权重最高的 4 根"，Three.js 本来就只支持 4 根，可以忽略。
- 导出后**再导入回来**确认骨骼数和顶点组都在。
- 同时导出到 `assets/models/`（素材留底）和 `public/models/`（程序运行时加载）。

## 四点五、接进煤球
1. 在 `src/pet/skins.ts` 对应动物下加一套皮肤，带上 `model: { file: 'models/xxx.glb', scale: 2 }`。
   scale 让它和代码版宠物差不多大：代码版黑猫身体加头长约 1.45、臀部离地 0.37。
   - `sheenColor`：毛绒边缘的绒光颜色。黑色毛用默认的灰蓝；**橘色、奶色毛要用暖色**（柴犬 `0x8a6a4c`），否则发灰；白色多的用中性浅灰（金鱼 `0x9a9aa4`）
   - `tailLiftScale`：尾巴跟着抬起放下的程度。**卷在背上的尾巴设小**（柴犬 0.2），否则坐下、睡觉时毛球会垂到地上
2. 打开 `http://localhost:1420/species-preview.html?only=0&skin=皮肤id&cell=420` 看 8 种姿势（`only` 是动物序号：0 猫 1 仓鼠 2 柴犬 3 金鱼）。
3. 右键桌宠 → 皮肤 → 切过去，在桌面上看走路、坐、趴、举牌子、躲窗口。

现在 AI 模型不会眨眼、竖耳朵、张嘴，也没有装扮；"踩地修正"会自动把最低的那只脚放回地面。

### 代码里踩过的坑（GltfQuadrupedModel.ts 已处理，改它时别改回去）
| 现象 | 原因 | 处理 |
|---|---|---|
| 拖动、右键不丝滑 | 对蒙皮网格做鼠标命中检测，要先在 CPU 上把 1 万个三角形按骨骼变形一遍：一次 33 毫秒（代码版 1 毫秒） | 每根骨头挂一个隐形椭球专门用来点击（大小按这根骨头带动的顶点算，去掉两头 3% 防止胡须撑大），蒙皮网格本身不参与检测：0.13 毫秒，和真实网格相比边缘误差约 10% |
| 走路一拐一拐、身体不协调 | 踩地修正用"迈步中的腿"去量，最低的那只脚每半步换一只，身体一步里上下跳 11cm | 先用不迈步的站姿量脚高做修正，再换成走路姿势；走路的上下起伏放到修正之后加：现在一步起伏 4.8cm（代码版 ±2cm） |
| 尾巴有一节"没了" | 代码版尾巴 12 节，AI 模型只有 4 根尾巴骨，照搬角度再乘 3 倍，尾尖那根转到 75°，关节处网格被拧扁 | 每根尾巴骨最多弯 0.45 弧度，相邻骨头的摆动节奏拉近 |
| 坐下时前爪悬空 | AI 猫身体比代码版长（屁股到胸口 0.66 对 0.48），坐下时胸口被抬得更高 | 踩地修正 |
| 主包超过 800KB | 引入了 GLTFLoader | 加载器按需 `import()`，只有选了 AI 皮肤才下载 |

**新动物做完后必须在桌宠里实际试**：走路（看身体有没有一顿一顿）、拖动和右键（看卡不卡）、开心甩尾巴（看尾巴是否完整）、坐下（看爪子是否着地）。

## 五、金鱼（不是四足，单独处理）

- 不绑四足骨架，也**不用 Tripo 绑骨**。用 `tools/blender/rig_fish.py`：
  ```python
  exec(open(r"D:/woke/homework/gongju/tools/blender/rig_fish.py", encoding="utf-8").read())
  armature, report = rig_fish("金鱼", armature_name="金鱼_骨架")
  ```
  骨骼：`body`（根）→ `head`；`body → spine → tail_0 → tail_1`（游动时一节节慢半拍地左右摆，形成 S 形）；`body → fin_left / fin_right`（胸鳍）。
  尾柄位置按"截面宽度第一次小于最宽处 25%"自动找。
- 代码：`src/pet/models/GltfFishModel.ts`，游动节奏照搬 `GoldfishModel`（悬浮 0.62、上下浮动、睡觉沉低）。皮肤里金鱼的 `model` 会自动用这个类。
- 粗糙度调到 0.72~0.8（比毛绒动物光滑一点，但别像塑料）。

### 金鱼提示词（第二次才成功）
