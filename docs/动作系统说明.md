# 煤球动作系统说明

煤球"平时做什么"和"对每件事怎么反应"，全部由一套统一的动作系统决定。
新增动作只需要在配置文件里加一条，不用改代码。

- 动作库：`public/config/cat-actions.json`
- 代码：`src/pet/actionSystem.ts`（挑选）、`src/pet/CatBrain.ts`（执行、能力）
- 检查工具：`node tools/validate-actions.mjs`（改完配置跑一下，写错了会列出来）
- 用户覆盖：`%APPDATA%\com.meiqiu.waterpet\config\cat-actions.json`（同 id 替换，`"disabled": true` 关掉，新 id 追加）

---

## 一、整体结构

```
 感知（发生了什么）           挑选（做哪个动作）                执行（怎么做）
 ─────────────────          ─────────────────               ─────────────────
 上一个动作做完了  ─┐                                        摆姿势（保持几秒）
 你摸了它          │       1. 按触发时机、位置、条件过滤       说话 / 冒字 / 声音
 你抱住它          │       2. 去掉冷却中、本小时次数用完的     转向（看鼠标、看你、背对你）
 你晃鼠标逗它      ├──▶    3. 打分 = 权重 × 心情 × 作息        调用能力：
 鼠标冲过去吓到它  │              × 活跃度 × 捣乱程度 × 新鲜度    散步、偷看、巡视窗口、捣乱、
 你喝了一杯水      │       4. 按分数加权随机选一个              追鼠标、跳上跳下、打滚……
 你回到电脑前……   ─┘       5. 做不成（如找不到藏身处）换一个
```

**现场情况**（挑选时用到的信息）：猫在哪儿（地面 / 窗口顶上 / 屏幕底边 / 原地不动）、心情、亲密度、
作息阶段、你在用什么软件、有没有全屏、是不是开会低调模式、你是不是在打字、鼠标在不在附近、
猫正在做什么、你多久没理它了、现在几点、星期几、设置里的活跃度和捣乱程度。

**新鲜度**：刚做过的动作分数会打折（默认刚做完只剩 40%，大约 90 秒后基本恢复），
所以同一个动作不会连着重复，整体看起来随机又自然。

## 二、一个动作怎么写

```json
{
  "id": "kneading",
  "name": "踩奶",
  "trigger": ["idle", "trick"],
  "where": ["floor", "edge", "window"],
  "when": { "intimacyAtLeast": 30 },
  "weight": 3,
  "moodWeight": { "happy": 2, "grumpy": 0.2, "angry": 0 },
  "phaseWeight": { "lunch": 1.5 },
  "cooldownSeconds": 60,
  "maxPerHour": 6,
  "steps": [
    { "pose": "sit", "seconds": [3, 5], "tweak": { "squint": 1, "legKick": 0.45 }, "sound": "purr", "float": "踩踩" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一名字（英文、数字、横线） |
| `name` | 中文名，方便看 |
| `trigger` | 触发时机，可以写一个或多个（见第三节） |
| `where` | 在哪儿能做：`floor` 地面 / `window` 窗口顶上 / `edge` 屏幕底边 / `anchored` 待在原地模式。不写 = 哪儿都行 |
| `when` | 条件，写了的都要满足（见第四节） |
| `weight` | 基础权重，越大越常见；0 = 不会被选 |
| `moodWeight` | 心情系数：`happy` / `normal` / `grumpy` / `angry` |
| `phaseWeight` | 作息系数：`morning` 刚上班 / `working` / `lunch` 午休 / `afternoonSlump` 下午犯困 / `almostOff` 快下班 / `overtime` 加班 / `beforeWork` 上班前 / `offDay` 休息日 |
| `activityLevelWeight` | 设置里的活跃度系数：`calm` / `normal` / `lively` |
| `mischiefLevelWeight` | 设置里的捣乱程度系数：`off` / `sometimes` / `often` |
| `cooldownSeconds` | 做完后多少秒内不再选它 |
| `maxPerHour` | 每小时最多几次 |
| `rejectsHold` | 只对 `hug` 有用：选到它表示挣脱，不让抱 |
| `steps` | 步骤，按顺序执行（见第五节） |

## 三、触发时机

| trigger | 什么时候 |
|---|---|
| `idle` | 平时：上一个动作做完了，想想接下来做什么 |
| `pet` | 被单击摸摸 |
| `hug` | 被按住不动（抱抱） |
| `hugEnd` | 抱完松开 |
| `teaser` | 你在它旁边快速左右晃鼠标（逗猫棒） |
| `scare` | 鼠标猛冲过去吓到它 |
| `drink` | 你喝了一杯 |
| `goalReached` | 今天喝水达标 |
| `snooze` | 喝水提醒点了"等一下嘛" |
| `reminderIgnored` | 喝水提醒没人理 |
| `customDone` | 定时提醒点了"做完啦" |
| `wakeUp` | 你回到电脑前，把它吵醒 |
| `trick` | 右键菜单"表演一个小动作" |

**和桌面窗口的互动**（窗口动态由 `src/pet/WindowMotionTracker.ts` 跟踪：移动速度、是否在被拖、是否被来回甩、新弹出、关掉、显示桌面）：

| trigger | 什么时候 |
|---|---|
| `coverExposed` | 躲在窗口后面，窗口被慢慢拖开，整个露出来了（被发现了）。宠物留在原地，不跟着窗口走 |
| `coverYanked` | 躲在窗口后面，窗口被猛地拽开（速度超过 1500 像素/秒） |
| `coverPartial` | 躲在窗口后面，窗口被拖开一部分（你停手后才反应） |
| `coverReturned` | 露出来以后，窗口又被拖回来盖住它 |
| `coverGone` | 藏身的窗口被关掉或最小化了 |
| `windowDropped` | 你把窗口拖到它身上 / 新窗口弹出来盖住了它（你停手后才反应；只是扫过去会吓一跳） |
| `rideSlow` | 站在窗口顶上，窗口被慢慢拖着走（坐车，每一趟最多一次） |
| `rideFast` | 站在窗口顶上，窗口被猛拖（超过 1300 像素/秒） |
| `shakenOff` | 站在窗口顶上，窗口被来回甩，被甩下来了（落地后） |
| `windowDragged` | 你在拖别的窗口（它看见了；平时还会转头盯着被拖动的窗口） |
| `desktopCleared` | 一下子最小化了所有窗口（显示桌面） |
| `windowPopped` | 旁边突然弹出一个新窗口 |

躲在窗口后面时，被挡住的部分按窗口**现在实际的位置**裁成透明：窗口挪开多少，宠物就露出来多少，和现实一样。

喝水提醒、定时提醒本身的流程（跑过去、举牌、敲窗、坐到窗口上、推杯子）比较复杂，仍由代码负责；
提醒之后的反应（稍后、忽略、做完）走动作系统。

## 四、条件（when）

| 条件 | 写法示例 | 含义 |
|---|---|---|
| `mood` | `["happy"]` | 心情 |
| `routinePhase` | `["lunch", "overtime"]` | 作息阶段 |
| `activity` | `["chat", "code"]` | 你正在用的软件：`chat` 聊天 / `meeting` 开会 / `video` 视频 / `shopping` 网购 / `browser` 网页 / `code` 写代码 / `sheet` 表格 / `doc` 文档 / `slides` 幻灯片 / `other` |
| `activityLevel` | `["lively"]` | 设置里的活跃度 |
| `mischiefLevel` | `["sometimes", "often"]` | 设置里的捣乱程度 |
| `roamMode` | `["free"]` | 散步模式：`free` / `anchored` / `edge` |
| `timeBetween` | `["22:00", "05:00"]` | 时间段，支持跨午夜 |
| `weekday` | `[1, 5]` | 星期几（1 = 周一 … 7 = 周日） |
| `intimacyAtLeast` / `intimacyBelow` | `30` | 亲密度（每天陪伴、摸摸、抱抱、逗猫都会增加） |
| `fullscreen` | `true` | 有没有全屏窗口 |
| `lowProfile` | `false` | 开会 / 全屏时的低调模式 |
| `typing` | `true` | 你是不是正在打字 |
| `cursorNearby` | `true` | 鼠标在不在猫附近 |
| `behavior` / `behaviorNot` | `["sleep"]` | 触发时猫正在 / 不在做的事 |
| `quietMinutesAtLeast` | `20` | 你多久没理它了（分钟） |
| `chance` | `0.3` | 其它条件都满足后，再加一道随机门槛 |

## 五、步骤（steps）

一步里可以同时写好几项：先执行说话、冒字、声音、转向，再摆姿势或调用能力。

| 字段 | 说明 |
|---|---|
| `pose` + `seconds` | 摆一个姿势保持几秒，`seconds` 可以写 `[最少, 最多]` 随机。可用姿势：`sit` 坐 / `stand` 站 / `groom` 舔爪洗脸 / `stretch` 伸懒腰 / `rest` 趴着 / `sleep` 睡觉 / `petted` 被摸 / `happy` 开心蹦 / `sulk` 背对生闷气 / `startled` 吓一跳 / `dodge` 躲开 / `scratch` 挠痒 / `yawn` 打哈欠 / `observe` 低头看 / `rolling` 打滚 / `swat` 拍一下 / `hugged` 被抱 |
| `tweak` | 在姿势基础上微调参数，例如 `{ "squint": 1, "tailWrap": 1 }` |
| `animate` | 让参数来回摆，例如 `{ "headYaw": { "amplitude": 0.8, "speed": 1.5 } }`（东张西望） |
| `spin` | 原地转圈速度（弧度/秒），例如追尾巴 `7` |
| `face` | 转向：`cursor` 看鼠标 / `user` 面向你 / `away` 背对你 / `random` |
| `say` | 说一句预生成语音的台词（台词分组名） |
| `text` | 只显示文字气泡，可以写多句随机选一句。平时的动作算"闲聊"（受设置里"话多程度"限制），对你操作的反应算"互动回应" |
| `float` | 头顶冒一个字或表情，可以写多个随机选 |
| `burst` + `burstCount` | 连着冒好几个 |
| `sound` | `purr` 呼噜 / `knock` 敲 / `crash` 摔碎 / `boing` 跳 / `meow:call`、`meow:short`、`meow:question`、`meow:scared`、`meow:complain` 猫叫 |
| `run` | 调用一个能力（见第六节）。能力接管后动作就结束了，所以 `run` 要写在最后一步 |

**常用姿势参数**（`tweak` / `animate` 里用）：
`headYaw` 左右转头、`headPitch` 抬头低头、`headRoll` 歪头、`eyeOpen` 睁眼程度、`squint` 眯眼（>0.55 变成 ^ ^）、
`pupilWidth` 瞳孔大小、`earBack` 飞机耳、`earPerk` 竖耳朵、`mouthOpen` 张嘴、`tailLift` 尾巴高度、
`tailSwing` 尾巴摆动幅度、`tailSpeed` 摆动速度、`tailWrap` 尾巴卷起来、`legKick` 蹬腿（踩奶）、
`crouch` 压低身子、`wiggle` 扭屁股、`knock` 抬右爪、`pawsOnLedge` 前爪扒边沿、`walkAmount` 原地踏步、`bounce` 弹跳。

## 六、能力（run）

| 能力 | 说明 |
|---|---|
| `wander` | 在空地上溜达（自动避开窗口） |
| `peek` | 找个窗口边躲起来偷看你 |
| `patrol` | 跳上一个窗口顶巡视 |
| `walkOnWindow` / `observe` / `hopToOtherWindow` / `jumpDown` | 在窗口顶上：溜达 / 低头看里面 / 跳到别的窗口 / 跳下来 |
| `roll` | 打滚 |
| `sleep` | 打个盹（40～90 秒） |
| `goEdge` | 去屏幕底边待着 |
| `flee` | 往远离鼠标的方向跑开 |
| `approachCursor` | 走到鼠标旁边喵一声 |
| `dodgeHop` | 往旁边跳开 |
| `pounceCursor` | 扭屁股扑鼠标（逗猫棒） |
| `rehideHere` | 就近在当前遮挡它的窗口边上重新躲好（之后照常探头偷看）；离得太远做不了 |
| `emerge` | 从窗口后面走出来，到最近的空地上 |
| `hideUnder` | 就躲在盖在身上的窗口下面，过一会儿再出来或探头 |
| `mischief:zoomies` / `mischief:pounce` / `mischief:occupyWindow` / `mischief:pushCup` / `mischief:follow` | 捣乱：满屏乱跑 / 扑鼠标 / 霸占窗口 / 推杯子 / 跟屁虫 |

需要新的复杂本事时，在 `CatBrain.runAbility` 里加一个能力，再在 `tools/validate-actions.mjs` 的能力清单里登记。

## 七、扩展建议

- **加一个小动作**：复制一个相近的动作，改 `id`、`name`、`steps`，调 `weight`。
- **让它只在某些情况出现**：加 `when` 条件，例如只在下午犯困时、只在你写代码时、亲密度 50 以上。
- **让它在某些情况更常见**：用 `moodWeight` / `phaseWeight` 调系数，比不加条件更柔和。
- **不想它太频繁**：加 `cooldownSeconds` 或 `maxPerHour`。
- **亲密度解锁**：用 `intimacyAtLeast`，越亲近解锁越多亲昵动作（踩奶 30、蹭蹭 15、融化 60……）。
- 改完运行 `node tools/validate-actions.mjs` 检查。

## 八、容错

- 动作写错的步骤会被跳过；没有姿势也没有能力的动作会自动补一个"坐 2 秒"，保证动作一定会结束。
- 所有候选都做不成时，猫会坐一会儿再重新挑。
- 大脑每帧自检：位置异常、原地来回抖动、行为切换过于频繁 → 自动复位到安全的地方；
  主循环出错不会让猫冻住；托盘菜单有"煤球卡住了？让它回到原位"。
