# 🐾 煤球 · 桌面喝水黑猫（内测版 0.1.0）

一只住在你桌面上的小黑猫：会在屏幕上溜达、跳到窗口上巡视、偷看你在干嘛，到点就用各种方式提醒你喝水。

## 安装

1. 双击 `MeiqiuWaterPet_0.1.0_x64-setup.exe`
2. 如果弹出蓝色的"Windows 已保护你的电脑"：点 **更多信息 → 仍要运行**
   （内测版还没有做数字签名，所以会有这个提示）
3. 安装完成后，煤球会出现在屏幕右下角；任务栏右下角的托盘里也有它的图标

系统要求：Windows 10 / 11（64 位）。

## 怎么跟它玩

| 操作 | 效果 |
|---|---|
| 单击猫 | 摸摸头（它心情不好时会躲开） |
| 双击猫 | 记一杯水 |
| 按住猫拖动 | 拎起来放到别处（可以放到窗口顶上，它会站在上面） |
| 右键猫 | 技能菜单：喝水、偷看、撒欢、散步模式、喝水统计、设置 |
| 托盘图标 | 显示 / 隐藏、立即提醒、喝水统计、声音开关、开机自启、设置、退出 |

## 它会怎么提醒你

- 默认每 45 分钟提醒一次，只在 09:00–17:30 提醒，午休 11:30–13:00 不打扰
- 根据你的喝水进度自动调整：喝少了就早点提醒
- 看你在做什么换提醒方式：打字时等你停下来、聊天时举牌、看视频和开会时不出声
- 不理它会升级：敲窗户 → 坐到你的窗口上 → 把杯子推下去
- 工作日 17:00 提醒录单子、17:30 提醒下班打卡（可以在设置里改或删）

所有时间、频率、声音、捣乱程度都能在 **设置** 里改。

## 隐私说明

- 煤球会读取 **窗口标题和程序名**（例如"微信""Excel"），只用来判断你在做什么、换个方式提醒你
- 它 **不会** 读取窗口里的内容，**不会** 记录你按了哪些键（只判断"是否在打字"）
- 喝水记录、心情等数据只保存在你自己电脑上：`%APPDATA%\com.meiqiu.waterpet\`
- 煤球不联网，不上传任何数据

## 卸载

在"设置 → 应用 → 已安装的应用"里找到 MeiqiuWaterPet 卸载。
想同时删除数据，再删掉 `%APPDATA%\com.meiqiu.waterpet\` 文件夹。
