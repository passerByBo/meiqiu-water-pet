# 🐾 煤球 · 桌面喝水黑猫（内测版 0.2.0，免安装）

一只住在你桌面上的小黑猫：会在屏幕上溜达、跳到窗口上巡视、偷看你在干嘛，跟着你的作息过日子，到点就用各种方式提醒你喝水。

## 怎么用

1. 把压缩包 **解压** 到一个固定的文件夹（例如 `D:\煤球`）
2. 双击 **`煤球.exe`** 就能用，不需要安装
3. 如果弹出蓝色的"Windows 已保护你的电脑"：点 **更多信息 → 仍要运行**
   （内测版还没有做数字签名，所以会有这个提示）
4. 煤球会出现在屏幕右下角；任务栏右下角的托盘里也有它的图标，右键托盘图标可以退出
5. 第一次用建议先打开 **设置**：填上你的称呼、上下班时间和午休时间

系统要求：Windows 10 / 11（64 位）。支持多块显示器、各种屏幕缩放比（100%～200%）。

⚠️ 如果在设置里开了"开机自动启动"，之后就 **不要再移动这个文件夹**，否则开机时找不到程序。

## 怎么跟它玩

| 操作 | 效果 |
|---|---|
| 单击猫 | 摸摸（呼噜、蹭蹭你；越熟越亲昵；心情不好时会躲开） |
| 双击猫 | 记一杯水 |
| 在猫身上 **按住不动 2 秒** | 抱抱（它会眯眼呼噜、冒小爱心；松开后开心打滚） |
| 在猫旁边 **快速左右晃鼠标** | 逗猫棒：它会压低身子扭屁股，扑过来拍一下；玩累了会趴下歇会儿 |
| 鼠标 **猛地冲过去** | 吓它一跳（会跑开、从窗口上跳下来、睡觉时被吓醒……） |
| 按住猫拖动 | 拎起来放到别处（可以放到窗口顶上，它会站在上面） |
| 右键猫 | 技能菜单：喝水、偷看、撒欢、**表演一个小动作**、散步模式、喝水统计、设置 |
| 托盘图标 | 显示 / 隐藏、立即提醒、喝水统计、**煤球卡住了？让它回到原位**、声音开关、开机自启、设置、退出 |

## 它的日常

- 有 90 多种小动作：舔爪洗脸、揣手手、追尾巴转圈、踩奶、招财猫招手、歪头卖萌、打喷嚏、东张西望……
  按心情、和你的亲密度、时间、你在用什么软件随机挑，不会老重复
- **跟着你的作息**：刚上班伸懒腰打哈欠、午休陪你睡午觉、下午犯困打瞌睡、快下班兴奋得坐不住、下班后还在忙会催你回家
- **亲密度**：每天陪伴、摸摸、抱抱、陪它玩都会增加；越熟解锁越多亲昵动作（蹭蹭、踩奶、翻滚、被摸到融化）
- **心情**：按时喝水它就开心；一直不理提醒会闹别扭、发脾气（背对你、不让摸）

## 它会怎么提醒你

- 默认每 45 分钟提醒一次，只在上班时间提醒，午休不打扰
- 根据你的喝水进度自动调整：喝少了就早点提醒
- 看你在做什么换提醒方式：打字时等你停下来、聊天时举牌、看视频和开会时不出声
- 不理它会升级：敲窗户 → 坐到你的窗口上 → 把杯子推下去
- 定时提醒：默认下班前半小时提醒录单子、下班时提醒打卡（跟着你设置的下班时间走）
  还可以自己加：固定时间提醒一次 / 下班前多少分钟 / 某个时间段内每隔多久提醒，并选择一周哪几天提醒

## 装扮奖励 🎀

好好喝水能解锁装扮，解锁后自动穿上，也可以在 设置 → 装扮 里换：

| 装扮 | 怎么解锁 |
|---|---|
| 🌸 小花发卡 | 第一次喝水达标 |
| 🎀 粉色蝴蝶结 | 累计 3 天达标 |
| 🧣 暖暖小围巾 | 连续 5 天达标 |
| 👑 小皇冠 | 连续 10 天达标 |

## 设置里能改什么

关于你（称呼）、作息（上下班时间、上班的日子、午休）、喝水提醒（间隔、稍后提醒、勿扰时段、全屏不打扰）、
定时提醒、饮水目标、声音（话多程度、音量）、外观与散步（大小、活跃度、捣乱程度）、装扮、开机自启。

## 隐私说明

- 煤球会读取 **窗口标题和程序名**（例如"微信""Excel"），只用来判断你在做什么、换个方式提醒你
- 它 **不会** 读取窗口里的内容，**不会** 记录你按了哪些键（只判断"是否在打字"）
- 喝水记录、心情、装扮等数据只保存在你自己电脑上：`%APPDATA%\com.meiqiu.waterpet\`
- 煤球不联网，不上传任何数据

## 删除

退出煤球（托盘图标右键 → 退出），然后删掉这个文件夹即可。
想同时删除数据，再删掉 `%APPDATA%\com.meiqiu.waterpet\` 文件夹。
